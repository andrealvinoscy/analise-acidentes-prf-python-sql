# Análise de Acidentes em Rodovias Federais

Projeto de análise de dados sobre acidentes em rodovias federais brasileiras, utilizando dados públicos da PRF.

## Objetivo

Praticar análise de dados utilizando Python, SQL, PostgreSQL e Power BI, passando pelas etapas de tratamento, armazenamento, consulta e visualização dos dados.

## Tecnologias utilizadas

- Python
- Pandas
- PostgreSQL
- SQL
- Power BI

## Etapas do projeto

1. Coleta dos dados da PRF ✅
2. Limpeza e tratamento com Python e Pandas - Em andamento...
3. Armazenamento dos dados no PostgreSQL
4. Consultas e análises utilizando SQL
5. Criação de dashboard no Power BI

## Período analisado

Dados de acidentes entre 2023 e 2025.
